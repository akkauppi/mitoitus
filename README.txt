DUBIOUS LITTLE PLANNING RULEBOOK — Mitoitus
Rules of thumb. Fingers crossed.

An experimental, open reference for urban design dimensions, spatial
relationships and urban morphology. Dubious brings together illustrated
design guidance, explicit calculations and reproducible measurements.
Sources, assumptions and measurement methods stay attached to the
knowledge they describe.

Rulebook: https://akkauppi.github.io/mitoitus/
Open data: https://akkauppi.github.io/mitoitus/data/
Morphology laboratory: https://akkauppi.github.io/mitoitus/morphology/

Eleven spreads combine original 3D dioramas, dimensional tables and dated
references. Open Sources for locators and scope. Overview shows static
figures. The offline ZIP includes those figures, structured data, the
morphology controls and metric CAD references. The rulebook prints to A3.

The data catalogue links the rulebook JSON and CSV, contextual assertions,
reference questions, worked examples, the morphology dictionary and exchange
schema. In the morphology laboratory, the residential capacity exercise compares
three synthetic slab alternatives and downloads the current inputs and results.
Use the integration guide in lab/docs/CITYMODEL-INTEGRATION.md to exchange
measurements and retain their methods and provenance.

Development, verification and packaging are documented in lab/README.md.
The root HTML and build-tools preserve the historical input. GitHub Pages
serves only the verified artifact built from lab/.

The project has no declared project-wide reuse licence. The vendored
